# Pop style

Inspired by SekaiPop’s outlined, tactile design language; implemented on top of the existing shell without importing SekaiPop code or assets.

- Cream outlines and hard shadows on bar groups and shared popup shadows.
- Mint clock accents, a pink control badge and a larger control-center header.
- Press feedback and visible focus outlines on shared buttons.
- Releasing a button outside its bounds cancels activation.
- Floating bar by default on fresh configurations. Existing bar preferences are preserved.

Toggle **Settings → Interface → Shell style → Pop style** to switch the styling live. The setting is persisted as `appearance.popStyle`. Wallpaper palettes and light/dark mode remain supported.

These changes build on the existing staged shell migration. They do not replace the shell with SekaiPop’s phone launcher or desktop editor.
